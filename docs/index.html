Features

Everything a CLI project needs, nothing it doesn't

CLight keeps the structure simple so you spend your time on commands, not on packaging.

Scaffold in one command

Run clight new in an empty folder, answer a short form, and get a working CLI project with an index file, a module and a README.

One place for imports

List every pip module once in imports.py. The index and all your modules share them, and CLight reads that file to detect dependencies.

Your command, anywhere

Each project registers its own CMD alias, so you can type your command from any folder once you restart CMD.

Publish to PyPI

Build and upload from your machine, or push to main on GitHub or GitLab and let the generated pipeline deploy for you.

A ready-made cli toolkit

Colored messages, prompts, progress bars, file helpers, sounds, speech and encryption, all through the shared cli class.

Semantic versioning built in

clight version bumps patch, minor or major for you, with alpha, beta and rc pre-release stages, and updates your README.

How it works

From empty folder to PyPI in three steps

Every project follows the same simple path.

  1. Create

    Open CMD in an empty folder and run clight new. Fill out the form once and CLight generates the project.

  2. Build

    Add public methods to .system/index.py. Each one becomes a command, and its trailing comment becomes the help text.

  3. Publish

    Bump the version with clight version, then publish with clight publish or just push to main.

Usage

A method is a command

Write plain Python methods. CLight dispatches the command, prints what you return, and builds help from your comments.

  • Return a string ending in ! to print an error
  • Return any other string to print a success message
  • Import every pip module once, in imports.py
Project structure 
from imports import *


class index:
    def __init__(self, app="", cwd="", args=[]):
        self.app, self.cwd, self.args = app, cwd, args

    def demo(self, param=""):  # (param) - Test demo method with param
        if not param:
            return "Invalid param!"
        cli.hint(param)
        return "Done"

FAQ

Questions, answered

Is CLight free to use?

Yes. CLight is open source under the MIT License, so you can use, copy, modify and distribute it for free.

Which operating systems does it support?

CLight itself targets Microsoft Windows: it registers its command aliases as .bat files and adds them to your PATH through the Windows registry. When you create a project you can pick its own target OS: OS Independent, Microsoft / Windows, POSIX / Linux or MacOS.

Do I have to write a setup.py or a packaging config?

No. When you publish, CLight builds the package for you. It reads your imports.py file to detect third-party dependencies and fills in the setup.py it needs, so you only write commands.

Where does my app get published, and how?

To PyPI. A Local project is published from your Windows machine with clight publish. A GitHub or GitLab project is deployed automatically when you push to the main branch.
